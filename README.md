# Кунлик вирд Telegram боти

## Telegram Mini App

Илова Telegram ичида очиладиган алоҳида интерфейси билан тайёрланди: [index.html](index.html). Улаш ва хостинг қадамлари [MINI_APP_SETUP.md](MINI_APP_SETUP.md) да.

Mini App’нинг биринчи саҳифаси — «Бугун»: тариқат вазифалари, робиталар, зикр саноқлари ва тавсиялар. Унинг кетидан «Вирдлар», «Намоз», «Ёдлаш», «Силсила» ва «Қўлланма» саҳифалари туради. «Силсила» ва «Ёдлаш»даги 41 пирлик номлар фойдаланувчи юборган «Силсилаи Шариф» рўйхати асосида киритилди. Маълумотлар шу папкадаги JSON файлларда сақланади; намоз вақтлари Islam.uz’дан API орқали олинади.

Биринчи марта очилганда фойдаланувчи Telegram орқали автоматик танилади. «Давом этиш ва синхронлаш» тугмаси босилса, мини-илова ва чатдаги `/today` бир хил саноқни `bot_data.sqlite3` базасидан ўқийди. Алоҳида пароль ёки регистрация шакли керак эмас. Розилик берилмаса, мини-илова қурилмадаги сақлаш усулида ишлайверади.

## Чатда ишлайдиган бот

Тўққиз дарснинг барчаси ҳар куни ўқилади. Ҳар бир дарснинг саноғи алоҳида юритилади ва янги кун бошланганда кунлик саноқлар нолдан бошланади. Синхронлаш розилиги берилгандан кейин саноқлар бошқа қурилмаларда ҳам кўринади.

## Ишга тушириш

1. Telegramда BotFather орқали бот яратиб, токен олинг.
2. Python 3.10 ёки янгироғини ўрнатинг.
3. Шу папкада қуйидагиларни бажаринг:

       python -m venv .venv
       .venv\Scripts\activate
       pip install -r requirements.txt

4. Токен ва сайтнинг HTTPS манзилини муҳит ўзгарувчиси қилиб беринг ва ботни ишга туширинг. Намоз вақтлари API’си ҳам шу процессда ишга тушади:

       $env:TELEGRAM_BOT_TOKEN="BotFather токени"
       $env:MINI_APP_URL="https://username.github.io/"
       $env:ADMIN_TELEGRAM_IDS="123456789"
       $env:PRAYER_API_PORT="8000"
       python bot.py

   Linux ёки macOSда муҳит ўзгарувчиси қуйидагича берилади:

       export TELEGRAM_BOT_TOKEN="BotFather токени"
       export MINI_APP_URL="https://username.github.io/"
       export ADMIN_TELEGRAM_IDS="123456789"
       export PRAYER_API_PORT="8000"
       python bot.py

   `username` ўрнига ўз сайтиңизнинг HTTPS манзилини қўйинг. `ADMIN_TELEGRAM_IDS` ўрнига Telegram’да `/myid` буйруғи билан олинган админ рақамини ёзинг. Бир нечта админни вергул билан ажратинг. `MINI_APP_URL` тўғри берилса, `/start` жавобида **Зикр нури** тугмаси чиқади.

5. Telegramда ботга `/start` ёзинг ва **Зикр нури** тугмасини босиб иловани очинг. Саноқларни бирлаштириш учун биринчи марта **Давом этиш ва синхронлаш** тугмасини босинг.

Сайтни GitHub Pages’да жойлаштириш ботни доим ишлатиб турмайди: GitHub Pages фақат саҳифани очади. Намоз жадвали, Telegram бот ва синхронлаш учун `bot.py` ишлаб турган компьютер ёки доим онлайн сервер керак. Агар API алоҳида доменда бўлса, `index.html` ва `admin.html` даги `prayer-api-url` мета майдонига API сервер доменини ёзинг. Маълумотлар `bot_data.sqlite3` файлида сақланади; хостингда бу файл доимий сақланадиган дискда бўлиши керак. Бот токенини GitHub’га қўйманг.

## Админ панели

- `/myid` — ўз Telegram ID рақамингизни кўриш.
- Шу рақамни хостингдаги `ADMIN_TELEGRAM_IDS` муҳит ўзгарувчисига киритинг ва ботни қайта ишга туширинг.
- `/admin` — Telegram’да админ панелини очиш.
- Панелда фойдаланувчилар сони, кунлик фаоллар, бажарилган вирдлар ва бўлимлар очилишининг сўнгги 7 кунлик умумий статистикаси кўринади. Фойдаланувчиларнинг шахсий ўқиш тарихи сақланмайди.

## Буйруқлар

- /start — бош меню
- /today — бугунги 9 дарс ва ҳар бирининг саноғи
- /guide — дарслар рўйхати
- /help — қисқа ёрдам
- /myid — Telegram ID рақамини кўриш
- /admin — админ панели
- /delete_data — профил ва шахсий саноқ маълумотларини ўчириш

## Матнни бойитиш

Дарслар `lessons.json` файлида сақланади. Ҳар бир дарсда `title`, `count` ва `content` майдонлари бор. Дарсларнинг тартиби массивдаги жойига қараб белгиланади.
