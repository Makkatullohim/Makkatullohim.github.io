# Кунлик вирд Telegram боти

## Telegram Mini App

Илова Telegram ичида очиладиган алоҳида интерфейси билан тайёрланди: [index.html](index.html). Улаш ва хостинг қадамлари [MINI_APP_SETUP.md](MINI_APP_SETUP.md) да.

Mini App’нинг биринчи саҳифаси — «Бугун»: тариқат вазифалари, робиталар, зикр саноқлари ва тавсиялар. Унинг кетидан «Вирдлар», «Намоз», «Ёдлаш», «Силсила» ва «Қўлланма» саҳифалари туради. «Силсила» ва «Ёдлаш»даги 41 пирлик номлар фойдаланувчи юборган «Силсилаи Шариф» рўйхати асосида киритилди. Маълумотлар шу папкадаги JSON файлларда сақланади; намоз вақтлари Islam.uz’дан API орқали олинади.

## Чатда ишлайдиган бот

Тўққиз дарснинг барчаси ҳар куни ўқилади. Ҳар бир дарснинг саноғи алоҳида юритилади ва янги кун бошланганда кунлик саноқлар нолдан бошланади. Mini App’да ҳар бир дарсга алоҳида соат белгилаб, сақласангиз, бот ҳар куни Тошкент вақти бўйича хабар юборади.

## Ишга тушириш

1. Telegramда BotFather орқали бот яратиб, токен олинг.
2. Python 3.10 ёки янгироғини ўрнатинг.
3. Шу папкада қуйидагиларни бажаринг:

       python -m venv .venv
       .venv\Scripts\activate
       pip install -r requirements.txt

4. Токен ва сайтнинг HTTPS манзилини муҳит ўзгарувчиси қилиб беринг ва ботни ишга туширинг. Намоз вақтлари API’си ҳам шу процессда ишга тушади:

       $env:TELEGRAM_BOT_TOKEN="BotFather токени"
       $env:MINI_APP_URL="https://username.github.io/"
       $env:PRAYER_API_PORT="8000"
       python bot.py

   Linux ёки macOSда муҳит ўзгарувчиси қуйидагича берилади:

       export TELEGRAM_BOT_TOKEN="BotFather токени"
       export MINI_APP_URL="https://username.github.io/"
       export PRAYER_API_PORT="8000"
       python bot.py

   `username` ўрнига ўз сайтиңизнинг HTTPS манзилини қўйинг. `MINI_APP_URL` тўғри берилса, `/start` жавобида **Зикр нури** тугмаси чиқади.

5. Telegramда ботга `/start` ёзинг ва **Зикр нури** тугмасини босиб иловани очинг. Кунлик саноқлар илова очилган қурилмада сақланади.

Сайтни GitHub Pages’да жойлаштириш ботни доим ишлатиб турмайди: GitHub Pages фақат саҳифани очади. Islam.uz’дан намоз жадвалини олиш ва Telegram ботни ишлатиш учун `bot.py` ишлаб турган компьютер ёки доим онлайн сервер керак. Агар API алоҳида доменда бўлса, `index.html` даги `prayer-api-url` мета майдонига фақат API сервер доменини ёзинг; масалан, `<meta name="prayer-api-url" content="https://api.example.com">`. Илова унга `/api/prayer-times` манзилини ўзи қўшади. Маълумотлар `bot_data.sqlite3` файлида сақланади. Бот токенини GitHub’га қўйманг.

## Буйруқлар

- /start — бош меню
- /today — бугунги 9 дарс ва ҳар бирининг саноғи
- /guide — дарслар рўйхати
- /help — қисқа ёрдам
- /delete_data — шахсий саноқ маълумотларини ўчириш

## Матнни бойитиш

Дарслар `lessons.json` файлида сақланади. Ҳар бир дарсда `title`, `count` ва `content` майдонлари бор. Дарсларнинг тартиби массивдаги жойига қараб белгиланади.

Бугунги кун чегараси BOT_TIMEZONE орқали танланади; бошланғич қиймати Asia/Tashkent.
